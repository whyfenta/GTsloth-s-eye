# ICD-10-CM 中英文對照檔

檔案：[`icd10cm-zh.csv`](icd10cm-zh.csv)。UTF-8（含 BOM），5 欄，97,447 列，一個代碼一列。

資料版本：健保署「2023年版_中文版ICD-10-CM/PCS(正式版)(115.08.27更新)」。健保自 114/1/1 起門、住診申報全面使用 2023 年版。

來源：衛生福利部中央健康保險署網站，健保服務 > 健保藥品與特材及醫療服務 > 醫療服務 > 國際疾病分類第十版 > [2023年版_代碼與醫令對應檔、對照檔](https://www.nhi.gov.tw/ch/lp-3847-1.html)，xlsx 版（8,248,417 bytes，115/10/28 下載）。

授權：依健保署[政府網站資料開放宣告](https://www.nhi.gov.tw/ch/cp-4379-5d212-3280-1.html)，網站刊載的資料以無償、非專屬、得再授權的方式提供公眾利用，使用時應註明出處。出處：衛生福利部中央健康保險署「2023年版_中文版ICD-10-CM/PCS」。

用途：處方警示（規則見 [rx-rules.md](rx-rules.md)）以中文顯示診斷碼的參考資料。網站程式不直接讀取本檔：`npm run rx-assets` 由本檔產生 `public/assets/rx/icd10cm.json`（代碼與中文名稱，含 2014 版已刪除的舊碼）。

## 欄位

| 欄位 | 說明 |
|---|---|
| 代碼 | ICD-10-CM 代碼，保留小數點，例如 `I25.10`。處方 QR 有的院所不寫小數點（`I2510`），比對時兩邊都去掉小數點。 |
| 可申報 | 原檔的 USE 欄。`1` 為可申報的最細碼（74,269 碼）；`0` 為類別標題（23,178 碼），例如 `C50.91` 還要第 6 碼標示左右側。 |
| 中文名稱、英文名稱 | 取自原檔，只去掉儲存格內的斷行：中文直接接回，英文換成空格。目前只有 `Z53` 一筆。 |
| 版本 | `2023` 為 2023 年版代碼（96,802 碼）；`2014已刪除` 為 2014 年版有、2023 年版已刪除的舊碼（645 碼），舊系統開的處方仍查得到名稱。 |

## 轉換方式

- `python scripts/icd10cm-zh.py <xlsx>` 讀原檔的「ICD-10-CM」與「2014_cm代碼刪除」兩個工作表，只用 Python 內建模組，寫出本檔。
- ICD-10-PCS（處置碼）與更新歷程、更新明細等工作表不收；原檔的狀態、修訂日期欄不收。中文名稱的修訂紀錄見原檔「更新歷程」「更新明細」。

## 使用注意

- 比對前把代碼去掉小數點並轉大寫。查不到完整碼時可以往前縮到類別碼取得名稱，但應標示不是完整碼。
- 健保署會修訂中文名稱（原檔更新歷程記錄 112～115 年多次修訂），更新時重新下載 xlsx 再執行轉換程式。
- 用 Excel 開啟後另存可能改變編碼與格式，請用程式讀取。
