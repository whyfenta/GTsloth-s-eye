# 健保用藥品項精簡檔

檔案：[`nhi-drug-codes.csv`](nhi-drug-codes.csv)。UTF-8（含 BOM），15 欄，45,292 列，涵蓋 45,217 個藥品代號。

資料基準日：115/10/25（2026-10-25）。來源為衛生福利部中央健康保險署的健保用藥品項資料（原檔 224,896 列、20 欄，含健保署給付規定與食藥署許可證連結），精簡方式見下方。

用途：以英文名、中文名、含量、劑型比對門市商品代號與健保藥品代號時的參考資料。比對結果存在[商品代號對照檔](sku-nhi-map.md)（放在另一個 private repo），`npm run nhi-map` 讀取這個檔案；網站程式不讀取。ATC代碼另供處方警示（診斷碼與藥品 ATC 的對照，規則見 [rx-rules.md](rx-rules.md)）使用：`npm run rx-assets` 由本檔產生網站載入的 `public/assets/rx/drugs.json`（健保碼、ATC代碼與成分）。

## 欄位

| 欄位 | 說明 |
|---|---|
| 藥品代號 | 健保藥品代碼，10 碼。錠劑膠囊末兩碼 `00` 為一般包裝、`G0` 為鋁箔包裝，同一藥品可能兩者並存；外用、眼用與液劑的末兩碼對應包裝規格（依本檔觀察，例如 `…321` 多為 5 GM、`…329` 多為 10 GM、`…421` 多為 5 ML）。 |
| 藥品英文名稱、藥品中文名稱 | 原樣保留。部分罕用字在來源檔已是「?」。 |
| 成分 | 成分與含量，複方以 `+` 連接。 |
| 規格量、規格單位 | 包裝規格，錠劑膠囊多為空白。 |
| 支付價 | 該列區間的支付價，0 表示這段期間不給付。 |
| 有效起日、有效迄日 | 民國年 `YYYMMDD`，`9991231` 表示未定迄日。 |
| 藥商、製造廠名稱 | 許可證持有藥商與製造廠。 |
| 劑型 | 健保登記劑型，例如膜衣錠、乳膏劑、點眼液劑。 |
| ATC代碼 | 原樣取自來源檔。每個藥品代號在完整歷史中只對到一個 ATC。42,819 列為 7 碼（第 5 階，成分層級）；其餘 2,473 列只到第 2～4 階（3～5 碼，例如 `N06BC`），比對時請以前綴處理。 |
| 最後給付價、最後給付迄日 | 由完整歷史算出：115/10/25 以前已生效、支付價大於 0 的最近一個區間的價格與迄日。目前仍給付的代碼即為現行價格；從未給付的 32 個代碼留空。 |

## 精簡方式

- 移除比對沒有用到的 7 欄：異動、單複方、藥品分類、分類分組名稱、給付規定章節、藥品代碼超連結、給付規定章節連結。
- ATC代碼起初也一併移除，115/10/28 為處方規則從同一份原檔補回：以藥品代號、有效起日、有效迄日逐列對回，45,292 列全部對到且其餘欄位一致，放在劑型之後。
- 每個藥品代號只保留有效迄日在 115/10/25 以後的列，也就是當天有效的區間加上已排定的未來異動。73 個代碼因此有 2 到 3 列，例如 115/11/01 起停止給付的眼藥。若只留最後一列，這些今天仍有給付的代碼會被誤判為支付價 0。
- 其餘欄位值逐字取自來源檔。來源檔曾經用 Excel 另存，支付價寫成 `0` 而非 `0.00`，日期沒有前導空白。
- 以這份精簡檔重跑一份 4,883 個商品代號的門市庫存簡表名稱比對，分類與候選健保碼和使用完整原檔時完全相同。

## 使用注意

- 判斷某一天是否給付，取有效起日 ≤ 該日 ≤ 有效迄日的那一列；同一代碼有多列時，起日較晚的是排定的異動。
- 資料只反映 115/10/25 當時的狀態，之後的健保公告異動需要重新下載原檔再精簡。
- 用程式讀取時，藥品代號與日期請當字串處理。用 Excel 開啟後另存可能改變數字格式。
